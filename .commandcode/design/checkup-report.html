HIGH

Sub-16px inputs cause iOS zoom-on-focus

All form controls render below 16px on small screens; iOS Safari auto-zooms into the field on focus, breaking layout mid-form. Location: widget/src/widget.css:150 and the control base.

FIX: Set font-size: 1rem on all input/select/textarea at widths below 640px, or unconditionally on form controls; keep labels at 0.875rem.
MEDIUM

Name row never goes two-column

First/last name stays stacked even on wide standalone. Location: widget/src/widget.css:189 (.fsb-row has no column template; the 560px container query never touches it).

FIX: At @container (min-width: 560px) add .fsb-row { grid-template-columns: 1fr 1fr } so names sit side by side.
MEDIUM

Phone grid squeezes in narrow embeds

The 2fr/3fr phone row truncates "United Kingdom (+44)" in a ~300px embed. Location: widget/src/widget.css:189-192.

FIX: Use minmax(0,1fr) minmax(0,2.5fr) and let the select label truncate, or stack on the narrowest widths.
